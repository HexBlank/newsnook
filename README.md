# 有所闻

> 一个不做算法推荐、不插广告、由用户自己选择信源的 Android 新闻聚合客户端。

有所闻是一款功能专一的新闻阅读应用。

它不根据阅读记录猜测你的兴趣，也不在信息流中混入广告、短视频、签到任务或垃圾推广。你可以自行选择分类和新闻源，把不同来源的内容整理到一个安静、清晰的阅读界面中。

项目参考了已经长期停更的「卡片新闻」。它曾经是一款非常简洁的新闻客户端：打开以后就是新闻，没有多余功能。由于旧版本在新 Android 系统上已经无法稳定运行，因此重新实现了一个适合当前设备使用的版本，并增加了多信源、翻译和离线阅读等能力。

## 功能特点

- **无算法推荐**：不建立兴趣画像，不根据阅读行为控制信息流
- **无广告与推广**：只展示新闻内容
- **多新闻源聚合**：在客户端直接获取并解析不同来源
- **分类与信源管理**：自由启用、关闭和排序分类及新闻源
- **综合频道**：将多个来源的内容汇总到同一频道
- **正文阅读**：提取文章正文，减少原网页中的无关元素
- **稍后读**：保存暂时没有读完的文章
- **离线存储**：缓存正文和列表，已打开的文章可离线阅读
- **中英文翻译**：支持对照翻译和全文替代
- **本地翻译**：下载语言包后可离线使用，不需要 API Key
- **云端翻译**：支持多种第三方翻译服务
- **纯客户端架构**：无自建业务后端，无须注册或登录
- **仅支持 Android**

## 理念

现在很多新闻应用的核心并不是帮助用户获取信息，而是尽可能延长停留时间。

兴趣推荐会不断强化已经表现出来的偏好，广告、软文、热榜和重复内容则进一步挤压有效信息。有所闻选择把控制权交还给用户：

- 看哪些分类，由用户决定
- 使用哪些信源，由用户决定
- 新闻如何排序和组合，由用户决定
- 是否翻译、使用哪种翻译方式，由用户决定

应用只负责获取、整理和呈现内容，不替用户判断“下一条应该看什么”。

## 翻译

有所闻支持两种译文呈现方式：

### 对照翻译

每段原文下方显示对应译文，适合阅读外文新闻、核对语义和学习语言。

### 全文替代

只显示译文，不保留原文，适合快速阅读。

当前可配置的翻译方式包括：

- Android 本地翻译
- Google Cloud Translation
- Microsoft Translator
- DeepL
- DeepLX

本地翻译需要先下载对应语言包，之后可以离线使用。

使用云端翻译时，待翻译文本会发送到用户自行选择和配置的第三方服务。各服务的可用地区、费用、配额和隐私政策，以对应服务提供方的说明为准。

## 离线阅读

完整打开过的文章会将正文文字和排版缓存到本机。再次打开时，无须等待原始站点返回内容。

稍后读文章会优先保留正文，普通文章则按照缓存空间和清理策略自动淘汰。

当前缓存主要分为：

- **正文缓存**：已提取的文章正文和排版
- **列表缓存**：各新闻源最近获取的条目

正文中的网络图片仍可能受 Android WebView、原始站点和网络状态影响。

## 架构说明

有所闻采用 **Backendless** 的纯客户端架构：

```text
新闻源
  ↓
Android 客户端请求
  ↓
列表解析 / 正文提取
  ↓
分类聚合 / 缓存 / 翻译
  ↓
本地阅读界面
```

项目不依赖自建业务服务器，新闻列表和正文由客户端直接获取并解析。

这种方式部署简单，也避免了维护中心化内容服务，但会受到原始站点接口、网页结构、访问限制和反爬策略变化的影响。新闻源改版后，相关解析规则可能需要同步更新。

## 隐私说明

- 应用无须注册和登录
- 项目不提供自建用户画像或推荐服务
- 阅读记录、稍后读和缓存主要保存在本机
- 本地翻译在设备上完成
- 使用云端翻译时，文本会发送到用户选择的第三方翻译服务
- 新闻正文和图片由对应新闻来源提供，访问过程可能受到其隐私政策约束

## 安装

请前往仓库的 **Releases** 页面下载最新 APK。

安装第三方 APK 时，Android 可能要求允许当前浏览器或文件管理器“安装未知应用”。

> 当前仅支持 Android，暂未提供 iOS、Windows、macOS 或 Web 版本。

## 新闻源说明

项目只对公开可访问的新闻列表和正文进行客户端聚合展示，不存储、不运营新闻内容，也不代表任何新闻机构。

新闻内容的著作权、商标权及其他相关权利归原作者和原发布平台所有。使用时请遵守对应网站的服务条款、robots 规则及当地法律法规。

如果某个来源不希望被聚合，或相关接口、页面结构发生变化，可以提交 Issue 说明。

## 已知限制

- 部分新闻源可能受地区、网络环境或访问频率限制
- 原始站点改版后，解析规则可能暂时失效
- 部分文章存在登录、订阅或付费阅读限制
- 图片、视频和交互内容不一定能够完整离线保存
- 云端翻译服务需要用户自行配置，且可能产生费用
- Android WebView 版本可能影响部分页面的显示效果
