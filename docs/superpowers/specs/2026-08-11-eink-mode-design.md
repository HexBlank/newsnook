# 墨水屏模式（einkMode）设计

> 日期：2026-08-11  
> 状态：已定稿，待实现  
> 范围：全局行为叠加（关动画、弱化装饰、文章分页阅读）；外观设置单开关  
> 不改：亮/暗主题色板语义、图片/视频加载与播放策略、翻译/评论/信源等业务偏好

## 1. 目标

让 Newsnook 在墨水屏设备上可长期舒适阅读：

- 关闭易造成残影的 UI 动画与装饰效果
- 文章改为电子书式左右点击翻页
- **一个总开关、零子配置**
- **关闭后完整恢复当前正常模式，零回归**

## 2. 决策摘要

| 项 | 选择 |
|---|---|
| 与亮/暗关系 | **行为层叠加**；颜色仍跟随 `theme: system \| light \| dark` |
| 模型 | 正交布尔 `einkMode`，**不是**第三主题 |
| 入口 | 外观设置手动开关；**不**自动检测设备 |
| 配置粒度 | 零子选项；开即全套，关即全撤 |
| 交付范围 | 完整可交付：关动画 + 弱化装饰 + 少滚动刷新副作用 + 分页阅读 |
| 媒体 | **沿用当前**图/视频策略，不做额外降级 |
| 最高约束 | `einkMode === false` 时行为与改前一致；关开关后无残留 |

## 3. 硬约束：正常模式零回归

1. **分支叠加，不改默认**：正常模式逻辑不因 eink 重写语义；eink 只走显式分支或 CSS `[data-eink]`。
2. **禁止顺手重构**正常 Reader / 动效管道「顺便整理」。
3. **共享模块保持纯净**：分页模块、eink CSS、eink 相关判断在 `einkMode=false` 时不得改变返回值或产生副作用。
4. **可逆性**：关闭后立即移除 `data-eink`、分页手势层、装饰覆盖；动效重新仅跟随系统 `prefers-reduced-motion`。
5. **验收门禁**：关 eink 的回归用例与开 eink 用例同等重要。

## 4. 偏好模型与运行时

### 4.1 字段

在现有 `Preferences` 增加：

```ts
einkMode: boolean  // 默认 false
```

- 不扩展 `ThemeMode`
- 不改 `resolveTheme` / `--tone-*` 色板
- 旧数据无此字段 → `normalizePreferences` 归一为 `false`

### 4.2 作用链

```
prefs.einkMode
  → 持久化（现有 preferences 存储）
  → document.documentElement.dataset.eink = '1' | 移除
  → useReducedMotion：系统 reduce OR einkMode → true
  → CSS [data-eink='1']：动画/过渡压制 + 装饰 token 覆盖
  → Reader：eink 时分页；否则现有滚动路径
```

### 4.3 关键约定

- **单一真相源**：只存 `einkMode`，不拆子偏好。
- **动效统一入口**：扩展现有 `useReducedMotion`（或等价薄封装），已接该 hook 的路径自动生效。
- **主题切换**：`einkMode` 开启时不启用 `theme-switching` 颜色过渡。
- **启动防闪**：`index.html` 内联脚本读 preferences 时同步写入 `data-eink`。
- **设置入口**：`AppearanceScreen` 主题区下方单一开关。

## 5. 全局动效与装饰降级

仅在 `data-eink='1'` 时生效。

### 5.1 动效

| 层 | 行为 |
|---|---|
| CSS | 对 `[data-eink='1']` 使用与 `prefers-reduced-motion: reduce` 同等的 animation/transition 压制 |
| JS | `useReducedMotion()` 在 eink 时恒为 `true`（列表/阅读入场、刷新脉冲、设置入场、边缘返回动画、开场 splash 等） |
| 主题切换 | 不写或立即结束 `theme-switching` |
| 加载态 | `ink-shimmer` / `animate-pulse` / 装饰性 spin 不播放；可用静态骨架（**不**改变是否加载图/视频） |

### 5.2 装饰（效果层，不改色板）

- `--shadow-lift` → `none`；常见 box-shadow 归零
- `--grain-opacity` → `0`
- `backdrop-filter` / blur → 关闭；半透明底改为不透明实色（仍用当前 `--tone-*`）
- 发光类阴影关闭

亮/暗文字、背景、链接色保持不变。

### 5.3 非阅读器滚动

- 列表/设置等**仍可滚动**
- `scroll-behavior: smooth` → `auto`
- 滚动驱动的 UI 显隐改为即时或固定显示（去掉动画）
- 业务逻辑（如分类切换是否刷新）不变，仅去掉伴随动效

### 5.4 例外

- 图/视频策略不变
- 功能必需的即时状态（如 `aria-pressed`、边框高亮）可保留，但无过渡动画
- Lightbox / 视频播放器局部 `data-theme="dark"` 可保留，但仍吃全局动效/装饰降级

## 6. 文章分页阅读

仅 `einkMode === true`。关闭后 Reader **完全**回到现有上下滚动体验。

### 6.1 点击分区

| 区域 | 宽度（竖屏建议） | 点击 |
|---|---|---|
| 左 | ~28% | 上一页 |
| 中 | ~44% | 切换顶栏/工具显隐 |
| 右 | ~28% | 下一页 |

- 进入阅读：顶栏默认显示
- 翻页：瞬时换页，无动画、无滑动翻页过渡
- 首页/末页越界：无操作
- **不以**左右滑手势翻页（避免与边缘返回、选文冲突）
- 左缘返回：保留为退出阅读；与左区点击冲突时，窄条边缘返回、其余区域上一页
- 点在链接、按钮、可交互控件上：不触发翻页
- lightbox / 评论抽屉 / 翻译面板打开时：分区翻页暂停，关闭后恢复

### 6.2 分页算法

- 以当前可视内容区高度为一页（扣除安全区与顶栏占位策略与实现一致即可）
- 按块级元素装页；尽量不在行中切开
- 超高单块（大图/视频）：优先独占一页；仅溢出时页内有限滚动（少整页刷新优先）
- 字号/行高/窗口变化 → 重新分页，尽量保持阅读锚点
- 翻译开关、正文重载 → 重新分页并落到锚点或第 1 页

### 6.3 进度

- 语义：`当前页 / 总页数`
- 顶栏可见时可显示页码；顶栏隐藏时不加额外浮层页码
- 再打开同文：恢复上次页；结构变化则落到最近锚点

### 6.4 与现有 Reader 能力

| 能力 | eink 分页下 |
|---|---|
| 图/视频 | 保留，策略同正常模式 |
| 评论 / 翻译 | 保留 |
| 链接 | 保留，不吞点击 |
| 表格横向滚动 | 页内必要横向滚动可保留 |
| 滚动显隐顶栏 | 停用 → 中区点击切换 |
| `revealReader` | 无（走 reduce 路径） |

### 6.5 结构

- Reader 内分页分支或抽出 `PagedReader`，由 `einkMode` 选择
- **滚动模式代码路径保持**，确保关闭 eink 后零回归
- 分页计算独立模块（纯函数 + ResizeObserver），便于测试

### 6.6 阅读中切换 eink

| 动作 | 结果 |
|---|---|
| 阅读中打开 | 按当前滚动锚点落到对应页 |
| 阅读中关闭 | 切回滚动；进度按锚点映射 `scrollTop`；不得残留分页手势层 |

## 9. 测试范围

### A. 正常模式零回归（必须）

- 默认 / `einkMode=false`：列表动效、主题过渡、Reader 滚动与 pill 显隐、边缘返回、图/视频、翻译、评论 —— 与改前一致
- 开过再关：上述全部恢复；无残留 `data-eink`、无分页点击层、无被永久关闭的动画

### B. 墨水屏开启

- 无过渡/入场动画；阴影/纸纹/blur 弱化；亮暗主题仍可切换且色正确
- 左/中/右点击正确；链接与控件不误触翻页
- 改字号/旋转后重分页且位置可理解
- 图/视频行为与正常模式相同

### C. 切换往返

- 外观页反复开关；阅读中开关；杀进程重启后 prefs 与 `data-eink` 一致

## 10. 明确不做

- 不把 eink 做成 `theme: 'eink'`
- 不自动检测墨水屏设备
- 不暴露关动画/分页/去装饰等子开关
- 不改变当前图片/视频策略
- 不在关闭 eink 后保留任何行为差异
