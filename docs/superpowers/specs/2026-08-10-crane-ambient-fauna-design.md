# 纸鹤行 · 物候氛围层设计

> 日期：2026-08-10  
> 状态：已实现  
> 范围：仅 `src/features/easterEgg/craneGame.html` 内画布物候与极轻环境音  
> 不改：彩蛋触发、`EasterEggShell`、阅读主路径、偏好存储、用户手册

## 1. 目标

在「纸鹤行」侘寂画面中加入**偶然、节气感、不参与交互**的生命气息：远鸟、竹上露珠、蝉影、虫迹等，使场景更有深意，同时保持整体美观、优雅、不抢玩法。

## 2. 决策摘要

| 项 | 选择 |
|---|---|
| 实现方式 | 画布物候层（方案 1），与四季/`weatherSys` 一体 |
| 密度策略 | 节气调度：春多飞鸟、夏蝉与露、秋虫、冬孤鸟 |
| 出现阶段 | 全程（标题 + 游玩）；游玩时更疏、更远、更淡 |
| 音效 | 极轻 Web Audio 合成音；服从现有「音」开关；禅模式静音 |
| 设置项 | 不新增；不引图片/音频文件 |
| 交互 | 零：不碰撞、不可点、不影响得分 |

## 3. 物候清单与四季

**画风：** 极淡墨线/剪影，低对比，水墨留白感；禁止写实生物与贴纸感。

| 元素 | 画法 | 春 | 夏 | 秋 | 冬 | 音（极轻） |
|---|---|---|---|---|---|---|
| 远鸟群 | 远山前 3–7 点墨折线鸟横掠 | 偶发 | 稀 | 偶发 | 更稀更远 | 偶有远啼 |
| 竹上露珠 | 竹节/叶缘小高光，偶滴落消失 | 晨感偶见 | 主戏（雨后更密） | 稀 | 几乎无（可霜晶点） | 滴落可选极轻 |
| 蝉影 | 竹干或叶背静止剪影，偶振翅 | 无 | 主戏 | 稀（残蝉） | 无 | 远蝉（对齐夏诗） |
| 虫迹 | 近/中景极淡弧线或小点缓移 | 稀 | 偶见 | 主戏 | 无 | 极轻虫鸣（秋） |
| 孤鸟 | 单只远鸟斜掠，比鸟群更淡 | 偶发 | 偶发 | 偶发 | 主戏 | 无或一声 |

换季时：旧物候淡出，新物候缓入。夏日俳句「蝉声入岩静无痕」与蝉/远蝉音对齐。

## 4. 架构

```text
主循环
  weatherSys.drawSky
  parallax.draw
  ambient.drawFar      ← 远鸟群 / 孤鸟
  particles.updateAndDraw
  ambient.drawMid      ← 虫迹
  bamboos.draw
  ambient.drawOnBamboo ← 露珠 / 蝉影（贴竹，随 sway）
  crane.draw
  UI
```

### 4.1 模块

在 `craneGame.html` 内新增 `ambient`（或等价命名）系统：

- `init` / `reset`：开局与重开清空实体
- `onSeasonChange(seasonIndex)`：调整权重与生成节奏
- `update(dt, context)`：生成、移动、生命周期；`context` 含 `playing`、竹列表、风、禅模式等
- `drawFar` / `drawMid` / `drawOnBamboo`：按层级绘制
- 实体硬上限约 **12**；掉帧时优先跳过/削减氛围层，不砍玩法

四季表为每季增加 `ambient` 配置（种类、权重、间隔、基础透明度）。游玩中相对标题页：生成间隔约 ×2、透明度约 ×0.6、更偏远景。

### 4.2 与竹的关系

露珠、蝉影在 `bamboos.draw` 之后、纸鹤之前绘制，位置绑定竹的 sway/叶角；**不修改**竹碰撞几何。

### 4.3 音效

扩展现有 `audioSys`（Web Audio 振荡器短音，无资源文件）：

- 播放条件：`config.audioEnabled && !config.zenMode`
- 音量明显低于拍翅 / 过关 / 死亡
- 触发稀疏，与视觉物候偶发对齐，禁止循环嘈杂底噪

禅模式下：氛围**视觉仍可出现**但更疏；氛围**音关闭**。

### 4.4 reduced-motion

若 `prefers-reduced-motion: reduce`：

- 不生成位移动效（鸟群飞掠、虫移、露滴落、蝉振翅）
- 允许极淡静止点缀（如贴竹蝉影、霜晶点）；禁止缓移与飞掠
- 氛围音关闭

## 5. 非目标

- 碰撞、得分、成就、可点击热点
- 新设置开关（「物语」等）
- 外部图片、精灵表、音频文件
- 改 `trigger` / Shell / App 返回栈 / 阅读 UI
- 写入用户手册或公开说明
- 写实或卡通贴纸风装饰

## 6. 测试要点

| 项 | 预期 |
|---|---|
| 四季切换 | 物候种类与密度符合第三节表 |
| 标题 vs 游玩 | 全程有；游玩更疏更淡更远 |
| 音开 + 非禅 | 偶发极轻环境音 |
| 音关或禅 | 无氛围音 |
| reduced-motion | 无氛围位移动画与氛围音 |
| 玩法 | 得分、碰撞、难度曲线不变 |
| 观感 | 不抢纸鹤与竹节；整体仍侘寂优雅 |

## 7. 风险

- 过密破坏留白：用上限 + 节气权重 + 游玩减半约束。
- 贴竹绘制若偏移明显：必须复用竹 sway 同一相位。
- 移动端性能：实体上限与掉帧时砍氛围层。

---

**验收一句：** 四季可感的偶然物候（鸟、露、蝉、虫）以水墨剪影点缀画面并可选极轻音，全程不参与玩法，且不破坏纸鹤行的侘寂气质。
