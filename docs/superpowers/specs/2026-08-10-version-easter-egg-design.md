# 版本彩蛋（连点「有所闻」）设计

> 日期：2026-08-10  
> 状态：已实现（`feat/version-easter-egg`）  
> 范围：今日顶栏（及桌面侧栏同名标题）连点触发；**仅打入当前版本彩蛋**，不保留历史版本实现  
> 不改：阅读主路径、偏好存储结构、账号/云、推荐、远程下发内容

## 1. 目标

在不打扰日常阅读的前提下，提供一个**隐藏、可换、随版本替换**的轻量彩蛋入口：

- 用户连续点击品牌名「有所闻」达到次数后打开彩蛋层。
- **每个安装包只携带本版彩蛋**；升级到新版本后，旧彩蛋代码与资源不再存在于仓库与产物中。
- 彩蛋内容形式不限：短文案、动效、小游戏等均可，但须服从「有所闻」视觉与克制原则。

## 2. 决策摘要

| 项 | 选择 |
|---|---|
| 触发点 | 今日信息流顶栏标题「有所闻」（`FeedScreen` 的 `title`）；桌面侧栏品牌「有所闻」共用同一触发逻辑 |
| 手势 | 连续点击 **5** 次；相邻两次间隔 **> 1s** 则计数归零 |
| 架构 | **单槽**：`features/easterEgg/current` 只实现本版内容；发版时替换/改写该槽，删除旧实现 |
| 历史 | **禁止**版本号路由表、禁止仓库内保留往期彩蛋模块 |
| 持久化 | 不写入 Preferences；不统计、不上报 |
| UI 壳 | 应用内主题遮罩层；禁止 `alert` / `confirm` / `prompt` |
| 文档 | **不**写入用户操作手册（保持隐藏） |

## 3. 用户流程

```
今日顶栏 / 桌面侧栏「有所闻」
  │ 点击
  ▼
连点计数（间隔 ≤ 1s 累加，否则归零）
  │ 达到 5
  ▼
打开彩蛋壳（墨底遮罩 + 内容槽）
  │ 关闭：关闭按钮 / 点遮罩（若内容允许）/ 系统返回
  ▼
计数清零；短冷却（如 800ms）内忽略再次触发，防连开
```

误触成本：标题区域小、需 5 次且 1s 窗口，日常滑动/点刷新不易触发。

## 4. 架构

```text
FeedScreen / DesktopSidebar
  → useEasterEggTrigger（连点状态机）
      → onUnlock → App（或壳宿主）setEggOpen(true)
          → EasterEggShell
              → <CurrentEasterEgg onClose={…} />   // 仅 current 槽
```

### 4.1 目录约定（建议）

```text
src/features/easterEgg/
  trigger.ts          # 连点：次数、间隔、冷却；与版本内容无关
  EasterEggShell.tsx  # 遮罩、关闭、返回键协作、reduced-motion 钩子
  current.tsx         # ★ 本版唯一彩蛋实现（发版时整文件替换或就地改写）
  index.ts            # 导出触发 hook / Shell / Current
```

禁止出现：`eggs/v1.4.7.tsx`、`EGG_BY_VERSION` map、按 `__APP_VERSION__` 动态 import 历史包。

### 4.2 内容槽契约

`current.tsx` 默认导出（或具名导出）一个 React 组件，例如：

```ts
export type EasterEggProps = {
  onClose: () => void
}

export function CurrentEasterEgg({ onClose }: EasterEggProps): JSX.Element
```

- 内容自行管理内部状态；关闭必须调用 `onClose`。
- 不得依赖「上一版本彩蛋是否解锁过」之类跨版本状态。
- 可选用 `sessionStorage` 做**本会话**内提示，但不得作为跨版本进度存档要求。

### 4.3 触发状态机（`trigger.ts`）

| 常量 | 值 |
|---|---|
| `TAP_TARGET` | 5 |
| `TAP_GAP_MS` | 1000 |
| `REOPEN_COOLDOWN_MS` | 800 |

行为：

1. 每次有效点击：若距上次点击 > `TAP_GAP_MS`，计数 = 1；否则计数 += 1。
2. 计数达到 `TAP_TARGET`：回调 `onUnlock`，计数归零，进入冷却。
3. 冷却期内点击只更新「最后点击时间」但不累加至解锁（或完全忽略，二选一；实现取**忽略累加**更简单）。

标题点击不得与其它顶栏控件冲突；仅绑在「有所闻」文字节点上。

### 4.4 壳层（`EasterEggShell`）

- **全屏不透明宿主**：`fixed inset-0`、实色 `bg-ink`（禁止半透明透出信息流）、高于底栏/侧栏的 z-index。
- **不提供通用 chrome**：顶栏关闭、边距、max-width、点遮罩关闭等一律由 `current` 自绘；壳只负责盖住底层并占满安全区。
- 系统返回由 `App` 现有返回栈优先关闭彩蛋。
- `prefers-reduced-motion`：壳本身无动效；内容侧自行降级。
- 无障碍：触发标题保持品牌名语义；关闭控件由 `current` 提供可见或 `aria-label`。

## 5. 本版内容槽

本版彩蛋为 **纸鹤行**（`current.tsx` + `paperCraneGame.ts`）：和纸鹤穿越水墨竹节的轻量竖屏/宽屏小游戏。整页自绘和纸纹理，关闭控件在页内。换版时删除上述文件并替换槽内容，不得归档旧实现。

手机：轻触振翅；桌面：点击或空格。`max-w-[800px]` 居中，窄屏略降竹速。

## 6. 发版约定

1. 升 `package.json` / `__APP_VERSION__` 时，检查彩蛋槽是否需要更换。
2. 更换步骤：改写 `current.tsx`（或替换实现 + 删旧依赖文件）→ 自测连点 5 次 → 确认产物中无旧文案/旧资源字符串。
3. Changelog / 用户手册：**默认不写**彩蛋；若维护者需要，仅可在内部 plan 备注。
4. Code review 关注点：是否误加版本表、是否误留上一版文件。

## 7. 非目标

- 远程下发 / 配置彩蛋内容
- 仓库内保留多版本彩蛋实现或按版本号切换
- 写入用户操作手册或关于页公开说明
- 彩蛋进度云同步、成就系统、排行榜
- 改变信息流布局或把彩蛋做成常驻入口
- 使用系统原生弹窗

## 8. 测试要点

| 项 | 预期 |
|---|---|
| 连点 5 次且间隔均 ≤ 1s | 打开壳并渲染 `CurrentEasterEgg` |
| 第 3 次后停顿 > 1s 再点 | 计数重置，需重新满 5 次 |
| 打开后短时间连点标题 | 不重复叠多层（冷却） |
| Android 返回键 | 先关彩蛋，不直接退出 App |
| reduced-motion | 首版无强烈扩散或可关闭 |
| 构建产物 | 仅含当前 `current` 文案/资源 |

可选：对 `trigger.ts` 抽纯函数做单元测试（注入时间戳）。

## 9. 风险与边界

- 标题可点后，偶发误触：5 次 + 1s 窗口已压低；不做 toast 提示「还差 N 次」。
- 桌面与手机双入口：必须共用同一 `onUnlock` / 同一 `eggOpen` 状态，避免两套壳。
- 单源聚焦等场景下 `FeedScreen` 的 `title` 可能不是「有所闻」：仅当展示文案为品牌名「有所闻」时启用触发（或仅主今日流挂载）；**单源标题不启用彩蛋**。

## 10. 实现顺序（摘要）

1. `trigger.ts` + 单测（若抽纯函数）
2. `EasterEggShell` + App 返回栈接入
3. `current.tsx` 首版墨点互动
4. `FeedScreen` 品牌标题可点；`DesktopSidebar` 品牌名可点
5. 自测手势 / 返回 / reduced-motion

---

**验收一句：** 主今日流连点「有所闻」5 次打开本版彩蛋；仓库与 APK 中不存在往期彩蛋实现；换版本只改 `current` 槽。
